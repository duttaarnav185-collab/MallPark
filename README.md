# 🚗 MallPark – Smart Mall Parking Dashboard

**MallPark** is a modern and responsive smart parking dashboard designed to simplify the parking experience inside shopping malls. It provides visitors with real-time parking availability, floor-wise parking visualization, occupancy analytics, and intelligent navigation to help them find the most convenient parking space effortlessly.

Built with a focus on **user experience, performance, and intuitive design**, MallPark transforms traditional parking management into an interactive digital experience through live parking updates, insightful analytics, and a clean dashboard interface.

Whether it's locating an available parking slot, checking occupancy statistics, or identifying EV charging stations, MallPark delivers a seamless and efficient parking solution with an elegant, responsive UI.

### ✨ Key Highlights

* 🚘 Floor-wise interactive parking layout
* 📊 Real-time occupancy analytics
* 🔍 Smart search & filtering
* ⚡ EV charging station indicators
* 📱 Fully responsive design
* 🌙 Dark Mode support
* 📈 Live parking simulation using mock data
* 🎯 Modern dashboard UI focused on usability

> **Making parking smarter, faster, and stress-free.**
